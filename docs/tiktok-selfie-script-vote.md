# Vote / Community Push

**Channel:** PLAYRIOT app TikTok
**Length:** ~25 seconds (short cut: ~15 seconds)
**Tone:** Black guy from Baltimore city, friendly, talking straight to camera — Baltimore sets the VOICE only; never say "Baltimore" in a script or caption (Cannon, 2026-08-13)
**Must hit:** link in bio · voting feature · follow + like (build the TikTok community)

---

## Main script (~25s, ~70 words)

```
Yo, what's good? So look — I build apps. Like, a new one every couple weeks. But here's the thing... I let YOU pick what I build next. For real. Link in my bio — tap that, it takes you to the board. Vote for the app you want, and I actually build the winner. Then hit that follow and drop a like, so you see it when your app goes live. That's it. Go vote. It takes like ten seconds.
```

## Short cut (~15s)

```
Yo, what's good? I build apps — and I let YOU pick what I build next. Link in my bio, vote for the one you want, I build the winner. Follow me and drop a like so you see yours when it drops. Go vote.
```

---

## Delivery notes

- Start the first line already moving (walking, sitting down, whatever) — a selfie video that opens mid-motion holds people past the first second.
- Small pause on "here's the thing" — that's the hook.
- Point down at the bio when you say "link in the bio."
- Film the longer one first — it sells "I actually build the winner," which is the whole reason to tap the bio.
